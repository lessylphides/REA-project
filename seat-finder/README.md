# 빈자리찾기 (매장 3D 빈자리 안내)

매장을 **만화 느낌 3D**로 보여 주고, 빈자리를 실시간으로 알려 주는 웹앱.

| 화면 | 주소 | 할 수 있는 것 |
|---|---|---|
| 손님 | `https://빈자리찾기.co.kr` | 빈자리 수·위치 보기 (돌려보기/확대만, **자리 터치 불가**) |
| 관리자 | `https://빈자리찾기.co.kr/관리자` (또는 `/admin`) | 비밀번호 로그인 → 자리 터치: **빈자리 → 손님 있음 → 빈자리** |

- 손님이 있는 자리에는 귀여운 캐릭터가 앉고, 빈자리는 바닥에 초록 불이 반짝입니다.
- 관리자가 바꾸면 손님 화면은 **3초 안에 자동 반영**됩니다 (새로고침 필요 없음).
- 관리자 화면의 **[전체 비우기]** = 마감할 때 한 번에 초기화.
- 아래쪽 칩(A1 2석 빔 …)으로 테이블별 빈자리도 표시.

### 1인칭 모드 (매장 안으로 들어가기)
[매장 안으로 들어가기] 버튼 → 카메라가 입구로 날아 들어가 **게임처럼 눈높이에서 걸어 다니기**.

| | 휴대폰 | PC |
|---|---|---|
| 걷기 | 왼쪽 아래 동그라미(조이스틱) | `W A S D` / `↑ ↓` (Shift = 빨리) |
| 둘러보기 | 화면 밀기 | 마우스 끌기 / `← →` |
| 나가기 | 오른쪽 위 [전체 보기] | `Esc` |

- 빈자리 위에는 **초록 표시**가 빙글빙글 떠 있음 (게임 목표 지점처럼)
- 화면 가운데 조준점을 자리에 맞추면 `B3-2 빈자리` 처럼 알려 줌
- 오른쪽 아래 **미니맵**: 내 위치·보는 방향 + 자리 상태(초록/빨강)
- 테이블·카운터·벽은 통과할 수 없음
- 관리자: 조준한 자리를 `E` 키(PC) 또는 자리를 직접 눌러서 바꾸기
- 링크로 바로 1인칭 시작: `https://빈자리찾기.co.kr/?walk`

## 구성
```
public/layout.js   ★ 매장 배치도 (벽·창문·테이블·의자 위치) ← 매장에 맞게 이것만 수정
public/app.js      3D 화면 (three.js, 툰 셰이딩 + 외곽선)
public/index.html  화면 틀 / 스타일
src/index.ts       Cloudflare Worker + Durable Object (자리 상태 저장, 관리자 확인, 화면 파일 제공)
scripts/build-assets.mjs  public/ → src/assets.generated.ts (배포 때 자동 실행)
```
- 저장: Durable Object 1개 → 모든 손님이 같은 상태를 즉시 봄.
- 서버 API: `GET /api/seats` (누구나) · `POST /api/seats/:id` · `POST /api/reset` (관리자 비밀번호 필요)

## 배포 (Cloudflare, smart-ac 와 같은 방식)
```bash
cd seat-finder
npm install
npx wrangler secret put ADMIN_TOKEN   # 관리자 비밀번호 (채팅/파일에 적지 말 것)
npm run deploy                        # public/ 화면 파일을 Worker 에 넣어서 배포
```
로컬 테스트: `.dev.vars` 파일에 `ADMIN_TOKEN=아무거나` 적고 `npm run dev` → http://localhost:8787

테스트 주소(현재 배포): https://seat-finder.hanguk-soek.workers.dev  ·  관리자: `/관리자`

## 한글 주소 연결 (빈자리찾기.co.kr)
한글 도메인은 내부적으로 **퓨니코드**로 바뀝니다: `빈자리찾기.co.kr` = `xn--ok0bu1teudt3lg0f.co.kr`

1. **도메인 구입**: 가비아·후이즈 등 국내 등록업체에서 `빈자리찾기.co.kr` 검색 후 등록
   (Cloudflare 에서는 .co.kr 을 직접 팔지 않음)
2. **Cloudflare 에 추가**: Cloudflare 대시보드 → 도메인 추가 → `xn--ok0bu1teudt3lg0f.co.kr` 입력 (무료 플랜)
3. 등록업체 관리 화면에서 **네임서버**를 Cloudflare 가 알려 준 2개로 변경 (반영까지 몇 시간)
4. `wrangler.toml` 의 `routes` 주석을 풀고 `npx wrangler deploy` → HTTPS 인증서 자동 발급

> 팁: 카카오톡·문자에서 한글 주소가 `xn--...` 로 보이는 경우가 있어, QR 코드로 매장에 붙여 두는 걸 추천합니다.
> 영문 주소(예: `binjari.kr`)도 하나 사 두고 같은 Worker 에 연결하면 안전합니다.

## 실제 매장 모습으로 바꾸기
### 방법 A — 배치도 수정 (추천, 지금 구조)
사진은 "참고 자료"로 쓰고, 3D는 귀여운 만화풍으로 다시 그리는 방식. 깔끔하고 휴대폰에서도 가볍습니다.
1. 매장을 **입구에서 1장, 네 모서리에서 각 1장, 천장 쪽에서 내려다보듯 1~2장** 촬영
2. 대략 치수: 매장 가로/세로, 테이블 크기와 위치(벽에서 몇 m), 의자 수
3. `public/layout.js` 에 숫자 입력 (테이블 `x, z, w, d, seats`, 창문, 카운터, 화분, 벽 색 등)
   → 사진과 치수를 주시면 이 파일은 대신 만들어 드릴 수 있습니다.

### 방법 B — 사진으로 3D 스캔 (.glb)
- 아이폰 **Polycam / Scaniverse / Luma AI** 같은 앱으로 매장을 돌면서 촬영 → `.glb` 로 내보내기
- 스캔은 실사 느낌이라 "애니메이션 느낌"을 원하면 **블렌더**에서 단순화 + 툰 재질로 손보는 작업이 필요
- `public/models/store.glb` 에 넣고 `layout.js` 의 `model: "/models/store.glb"` 로 지정
  → 스캔 모델 위에 의자·손님만 올라갑니다. (테이블 좌표는 스캔과 맞춰야 함)

## 자리 번호 규칙
테이블 id + 번호 → `A1-1, A1-2, …`, 바 좌석 `BAR-1 …`
테이블 id 를 바꾸거나 지우면 그 자리의 기존 상태는 무시됩니다(다음 [전체 비우기] 때 정리).
